## 🚀 核心功能模块

### 1. 3D 空间交互与专业课计算工具
1. **晶面 / 晶向标定与 3D 剖切（密勒指数）**（`#crystal`）
   - 支持立方晶系与六方晶系；
   - 自由绘图与自主识图训练双模式无缝切换；
   - 动态计算并高亮 Miller 晶面指数 $(hkl)$ / 晶向指数 $[uvw]$ 空间截面几何多边形；
   - 悬浮自测 HUD 位于左下方，视野开阔无遮挡。
2. **极射赤面投影**（`#stereographic`）
   - 乌尔夫网（Wulff Net）空间三维极射赤面投影；
   - 支持“模型一”、“模型二”、“模型三”多阶密度切换；
   - 晶面极点、晶面指数、特征晶带与赤道基面独立胶囊芯片开关。
3. **铁碳相图（Fe-Fe3C）动态计算**（`#iron-carbon`）
   - 动态成分-温度十字光标交互拾取；
   - 全相区智能判定；
   - 实时执行**杠杆定律**，自动测算平衡态相组成物（$\alpha$、$\text{Fe}_3\text{C}$）与室温显微组织组成物（珠光体、二次渗碳体、莱氏体等）质量百分比。
4. **晶体结构（3D）**（`#typical-structures`）
   - 包含金刚石、富勒烯（C₆₀ 巴基球）、石墨、碳纳米管、石墨烯等碳单质与同素异形体；
   - 包含 NaCl (岩盐结构)、CsCl 结构、ZnS (闪锌矿结构)、ZnS (纤锌矿结构)、CaF₂ (萤石结构)、TiO₂ (金红石结构)、α-Al₂O₃ (刚玉结构)、CaTiO₃ (钙钛矿结构)、MgAl₂O₄ (尖晶石结构)、[SiO₄] 硅氧四面体等离子与共价晶体模型。
5. **点阵与间隙（3D）**（`#interstitial`）
   - BCC / FCC / HCP 点阵原子整体联动开关；
   - BCC 密排面 $(110)$ 同步贯穿绘制双向体对角线密排晶向 $[111]$；
   - 符号严谨规范：密排面统一使用圆括号 $(110)$，密排方向统一使用方括号 $[111]$；
   - 八面体间隙 / 八面体间隙中心、四面体间隙 / 四面体间隙中心独立观察与半径比测算。
6. **位错交割与动力学（3D）**（`#dislocation`）
   - 刃型位错与螺型位错运动干涉；
   - 割阶（Jog）与扭折（Kink）形成的动力学三维可视化演变过程。
7. **空间立体三元相图（3D）**（`#ternary-phase`）
   - 固态互不溶解三元共晶立体三棱柱曲面模型；
   - 纯净专业三维空间视角，等温水平截面与变温垂直截面剖切；
   - 底部相区图例采用严谨方块标注。

## 🛠️ 技术架构

- **前端架构**：原生 ES Modules（ESM），无需 Webpack/Vite 繁琐打包，开箱即用；
- **3D 引擎**：Three.js + OrbitControls（手势/鼠标自由平移、旋转与缩放）；
- **公式排版**：KaTeX 客户端数学公式渲染；
- **存储方案**：客户端 `localStorage` 离线持久化存储学习进度、做题记录与收藏夹；
- **托管兼容**：纯静态托管，零后端维护成本，支持 Cloudflare Pages、Vercel、GitHub Pages、Nginx。

## 💻 本地运行

无需安装复杂的构建工具，只需任意静态文件服务即可：

```bash
# 使用内置 Node.js 启动本地服务：
node server.js

# 打开浏览器访问：
http://127.0.0.1:8089/
```
